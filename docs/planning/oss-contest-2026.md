# 2026 오픈소스 개발자대회 — GoNow 팀 참고용 요약

원문: `2026년 오픈소스 개발자대회운영규정.pdf` (2026.06 시행). 이 문서는 "운영규정"(자격·라이선스·검증·제재 등 절차 규정)만 다루고, **대회 주제·심사 배점·제출 서식·마감일 등은 별도의 모집 공고에 있음** — 그건 아직 확보 못 했으니 따로 확인 필요.

---

## ⚠️ GoNow 저장소 기준으로 지금 확인/조치가 필요해 보이는 것

1. **LICENSE 파일이 두 저장소 모두 없음** (`GoNow_Fronted`, `gonow-spring` 확인함) — 대회 규정상 직접 작성한 소스코드 전체에 **OSI 인증 오픈소스 라이선스**(MIT, Apache-2.0, GPL-2.0/3.0, LGPL, BSD 등)를 적용해야 함. 출품 전 두 저장소에 LICENSE 파일 추가 필요.
2. **저장소가 실제 Public인지 확인** — 대회는 GitHub 등 공개 저장소 게시가 필수이고, 수상 시 **수상일로부터 5년간 Public 유지 의무**(임의로 Private 전환 시 수상 취소 가능).
3. **사용 중인 오픈소스 라이브러리/프레임워크 출처·라이선스 정리 필요** — 출품 시 활용한 모든 오픈소스(Spring Boot, Expo, notifee, expo-location 등)의 출처·라이선스를 명시해야 함.
4. **정부 지원사업 중복 수혜 여부 확인** — "대학 자체 예산 사업"은 중복수혜 규정에서 명시적으로 제외되지만, 별도로 정부 R&D/지원사업 예산이 들어간 적이 있다면 신고 대상이니 팀 내에서 한 번 확인.

## 참가 자격 (제4~6조)
- 대한민국 국민만 참가 가능 (외국인 불가)
- 개인(1인) 또는 팀, **인원 제한 없음**, 소속/지역 무관
- 학생부문(초중고 + 대학(원) 재학·휴학생) vs 일반부문(그 외) — **학생+일반 혼합 팀은 무조건 일반부문**으로 참가
- 참가 부문은 **접수 마감일 기준 신분**으로 확정(이후 졸업 등 신분 변동은 영향 없음)
- 동일인이 여러 팀에 중복 참가하거나 개인/팀 교차 참가 불가 — 적발 시 관련 팀 전체 참가·수상 취소

## 라이선스·저작권 (제7~10조)
- 출품작 저작권은 팀(참가자)에게 귀속되고 수상 후에도 유지. 주최 측은 홍보 목적으로만 활용
- **직접 작성한 소스코드 → OSI 인증 라이선스 필수.** 비상업 전용 라이선스는 원칙적으로 불가(예외는 저작권자의 별도 서면 허락이 있을 때만)
- 타인의 저작물을 썼으면 출처·라이선스 명시
- 전체 소스코드 제출 + GitHub/Hugging Face 등 공개 저장소 게시 필수, 심사·검증 가능한 상태 유지
- 수상팀은 저장소를 **5년간 Public 유지**해야 함

## AI 모델 활용 규정 (제9조, [별표2]) — 새 기능 아이디어 낼 때 특히 참고
- AI 모델을 넣는다면 최소 **오픈웨이트 수준**(가중치 공개, 예: LLaMA/Gemma/Mistral/Qwen) 이상이어야 함. 승인된 사람만 접근 가능한 폐쇄형 모델은 사용 불가.
- **중요한 제약**: "외부 상용 API 호출로만 작동하는 서비스"(예: GPT/Claude API 붙여서 답변만 보여주는 형태)는 **원칙적으로 출품 제한 대상**.
- **예외이자 사실상 권장 방향**: MCP(Model Context Protocol) 등 **"AI 모델과의 연동 생태계 자체를 구축하는 소프트웨어"**는 명시적으로 허용·권장됨(연동 테스트용 API 호출은 허용).
  - → GoNow에 AI 기능을 얹을 거면, 단순 챗봇 API 래핑보다는 **오픈웨이트 모델을 직접 탑재/파인튜닝**하거나 **MCP류 연동 도구**를 만드는 방향이 규정상 안전하고 대회 취지에도 맞음.
- 참고로 카카오맵/ODsay 같은 **일반 지도·경로 API는 "AI 모델"이 아니므로 이 조항 적용 대상이 아님** — 기존 서버 구조(스프링↔플라스크↔외부 지도 API)는 그대로 문제없음.
- 개발 중 코드 작성/디버깅 보조로 Claude/GPT 등을 쓰는 건 허용되지만, **AI가 짠 코드를 팀원이 이해하지 못하면 심사에서 감점될 수 있음** — AI가 생성한 코드는 리뷰/이해하고 넘어가야 함.
- AI 모델을 실제로 탑재/적용하면 별도 지정 서식으로 모델 정보를 추가 제출해야 함(서식은 모집공고 쪽에 있을 가능성 높음).

## 평가 관련 참고 (제16조)
- 팀 내 역할은 명확히 구분돼야 하고 **개인별 기여도가 심사에 반영**됨 → 커밋 로그 등으로 각자 기여가 드러나게 관리해두면 유리
- 대회 주제와 무관한 출품작은 해당 단계 0점/즉시 제외 — **"대회 주제"가 뭔지는 이 문서에 없음, 모집 공고에서 별도 확인 필요**
- 결격 사유(저작권 침해/모방/대리개발, 중복수혜)로 판명되면 평가 제외 또는 수상 취소+상금 환수
